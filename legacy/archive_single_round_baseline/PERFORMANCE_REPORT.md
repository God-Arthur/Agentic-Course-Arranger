# 对照实验性能报告

- 生成方式：`python run_experiments.py`（全部指标由代码计算，LLM 不参与打分）
- 每组配置：72 名合成学生 / 随机种子 [1, 2, 3, 4, 5, 6, 7, 8] / 信息预算 30 次询问 / 每轮 4 题
- 运行时间：2026-10-16 09:28:36
- 报告重渲染时间：2026-10-16 10:06:17（只重算汇总与排版，未重新运行任何机制臂）
- LLM 通道：模型 agnes-3.0-flash，本地限流 20 请求/分钟，失败按 Retry-After 或指数退避重试；任何回退的运行都不作为 AI 效果证据
- 数据：合成数据，不含任何真实学生记录

## 1. 机制定义

| 组别 | 机制 | 作用 |
| --- | --- | --- |
| A | 现行机制基线 | 优先级组 + 随机抽签 + 顺序志愿的简化模拟，仅作对照，不是浙大官方算法复刻 |
| B0 | 一次性优化（无交互） | 只用初始志愿求解，用来扣除“优化器本身”的贡献 |
| B | 规则式集体规划 | 透明启发式选择询问对象，用来判断收益是否只来自额外交互 |
| C | AI 集体规划 | LLM 观察全局状态并选择结构化行动，与 B 共用候选集、优化器和预算 |
| D | 完整信息参照 | 向优化器披露全部隐藏偏好，估计信息缺口的上限，不可部署 |

## 6. 结论边界

- 总效用更高不等于更公平；课位利用率更高也不等于配置更好。请同时查看低分位效用与分组效用。
- 所有效用都在合成隐藏偏好上计算，不能外推为真实校园效果。
- C 组只有在 LLM 实际返回结构化选择且没有回退到规则策略时才能作为 AI 效果的证据；任何回退运行都被标记为无效并从均值中剔除。
- D 组不可部署，它只用于估计“信息缺口”还能贡献多少，而不是证明某种制度更优。
- A 组是对现行机制的简化模拟；真实优先级顺序、先修规则和二轮规则需由教务授权数据替换后重跑。
